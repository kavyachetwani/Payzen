# /voice — Hinglish Escalation Node

**Built in: Stages 10–12**

Isolated Hinglish conversational agent for the hardest/highest-value recovery cases.
Uses few-shot prompted sarvam-m — the only LLM usage in the entire system.

This is the ONLY component that uses an LLM. All diagnosis, decision-making, and
audit logging are deterministic/statistical.
